## How to Setup and Run the Project

Follow these steps to get the website running locally on your computer:

### 1. Prerequisites
Make sure you have [Node.js](https://nodejs.org) installed on your computer (Version 18 or higher is recommended).

### 2. Clone the Repository
Open your terminal, navigate to the folder where you want to save the project, and run:
```bash
git clone <PASTE_YOUR_GITHUB_REPO_URL_HERE>
```

### 3. Open the Project Folder
Move into the project directory:
```bash
cd <PASTE_YOUR_FOLDER_NAME_HERE>
```

### 4. Install Requirements / Dependencies
Because the `node_modules` folder is excluded from GitHub, you need to download the project requirements locally. Run this command:
```bash
npm install
```

### 5. Run the Local Server
Once the installation finishes, launch the development server by running:
```bash
npm run dev
```

### 6. View the Website
Open your browser and go to the local link provided in your terminal (usually `http://localhost:5173`).




# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
